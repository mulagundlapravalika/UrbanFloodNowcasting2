# UrbanFloodNowcasting2
Urban Flood Nowcasting is a smart AI-powered system that predicts and monitors urban flooding using rainfall, drainage, weather, and location-based data. It provides early warnings, flood-risk insights, and real-time information to help citizens and authorities take timely action and reduce flood damage.
